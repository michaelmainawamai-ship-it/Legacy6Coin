# Legacy6Coin (L6C) Disclosure Ledger

This public ledger is intended to document material Legacy6Coin events and provide a consistent record for community, governance, and review purposes. Record entries for:

- Liquidity additions
- Liquidity removals
- Treasury transfers
- Founder wallet disclosures
- Ownership changes
- Significant issuance events

Include transaction hashes, wallet addresses, dates, amounts, purposes, and relevant public notes where applicable and available. Add new entries below using the template. Do not treat blank fields as confirmation that an event did not occur.
